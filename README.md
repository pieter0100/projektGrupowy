# Multiplication Learning Game

## Features

* **Engaging Game Modes:**
  * **Multiple Choice:** Select the correct answer from a set of options.
  * **Match Pairs:** Connect the multiplication equation with its correct product.
  * **Typed Answers:** Challenge memory and typing skills by entering the exact answer.
* **Learning Sessions:**
  * **Practice Mode:** A relaxed environment to practice specific times tables.
  * **Exam Mode:** Timed challenges to test mastery and earn high scores.
  * **Learn Mode:** Step-by-step introduction to new multiplication concepts.
* **Gamification & Progression:** * Unlock new levels as math skills improve.
  * Global and local **Leaderboards** to encourage friendly competition (Coming soon).
  * Comprehensive user statistics tracking (Coming soon).
* **Offline-First Architecture:** Kids can play and learn anywhere, even without an internet connection. Progress is saved locally and automatically synchronized with the cloud once a connection is re-established.
* **Secure Accounts:** Firebase-powered authentication to keep user profiles and progress safe across devices.
